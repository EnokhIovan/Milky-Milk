*>. Ide game dari Yovan:*
- Referensi game dari Russian Roulette.
- Ada sistem ekonomi (uang dan shop).
- Setiap kali selesai permainan, player mendapatkan EXP dan uang.
- Ada item buat penunjang match (misal heal, acak isi peluru, dll).
- Game bersifat endless, dapat dimainkan berulang kali.
- Game mula mula melawan 1 orang, akan bisa melawan lebih dari 1 orang (maks 4) dengan sistem unlock (bisa memakai experience level atau uang).
- Ada upgrade an.

*>. Pengembangan Game David*
- Judul: Color.IO

- Lore :
>> Dunia kehilangan semua warna karena makhluk bernama The Void.
>> Semua benda masih ada, tapi kehilangan "jiwanya".
>> Player adalah pelukis terakhir yang bisa mengembalikan warna.
>> Semakin banyak warna kembali...
>> Dunia mulai hidup lagi.

- Gameplay:
>> Masuk level.
>> Cari sumber warna.
>> Warnai dunia.
>> Unlock mekanik baru.
>> Buka area berikutnya.

- Mekanisme:
>> Biru  -> Buat jalan normal.
>> Hijau -> Buat lompat (trampolin).
>> Ungu  -> Teleportasi (opsional tergantung programmernya [Inisial Titan4]).
